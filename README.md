# Polyglotica AI — Database Design and Business Process

Relational database design for a language-learning platform: schema, triggers and business queries in MySQL, with the business process documented alongside.

Course project for Storing and Retrieving Data, MSc in Data Science and Advanced Analytics, NOVA IMS.

## What the project does

- Designs the entity-relationship model and MySQL schema for the platform.
- Implements triggers to enforce business rules.
- Answers business questions with SQL: window functions, aggregations and pivot tables.
- Documents the business process the database supports.

## Repository contents

| File | Description |
| --- | --- |

| `polyglotica_ai_queries.sql` | Business queries |
| `video_link.txt` | Link to the project video |

## How to run

1. Run `polyglotica_ai_db.sql` in MySQL to create the database.
2. Run the queries in `polyglotica_ai_queries.sql`.

## Tech stack

MySQL · SQL · ERD · triggers · window functions
